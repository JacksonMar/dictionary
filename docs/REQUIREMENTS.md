# Вимоги: macOS-застосунок «Словник» (EN → UK) з додаванням слів через контекстне меню

## Що робить застосунок

Користувач виділяє англійське слово чи фразу в будь-якій програмі (Safari, Chrome, PDF, Notes тощо), натискає праву кнопку миші → **Services / Служби → «Додати в словник»**. Застосунок:
1. отримує виділений текст;
2. запитує Claude API: переклад, транскрипцію (IPA), частину мови, приклад речення;
3. зберігає запис у словник;
4. показує системне сповіщення: «Додано: *word* — переклад» (або «Вже є в словнику»).

## Технічний стек (обов'язково)

- Swift 5.9+, SwiftUI, мінімальна версія macOS 13.
- Інтеграція в контекстне меню — через **macOS Services** (`NSServices` в Info.plist, `NSApp.servicesProvider`, тип даних `NSStringPboardType` / `public.utf8-plain-text`). Після встановлення викликати `NSUpdateDynamicServices()`.
- Проєкт генерується через **XcodeGen** (`project.yml`).
- Застосунок працює як **menu bar app** з можливістю відкрити головне вікно словника. Опція «Запускати при вході в систему» (`SMAppService`).
- Без сторонніх залежностей. Мережа — `URLSession`, async/await.
- Підпис — локальний (ad-hoc), App Store не потрібен.

## Claude API

- Endpoint: `https://api.anthropic.com/v1/messages`, заголовки `x-api-key`, `anthropic-version: 2023-06-01`.
- Модель налаштовується в Settings, за замовчуванням — `claude-haiku-5-5`.
- API-ключ вводиться в Settings і зберігається **тільки в Keychain**. Ніколи не в коді, логах чи JSON словника.
- Промт вимагає відповідь **лише валідним JSON** за схемою:
```json
  {
    "word": "run",
    "lemma": "run",
    "part_of_speech": "verb",
    "transcription": "/rʌn/",
    "translations": ["бігти", "керувати"],
    "example": { "source": "She runs every morning.", "translation": "Вона бігає щоранку." }
  }
```
- Відповідь валідувати. Якщо JSON невалідний — одна повторна спроба, потім помилка.
- Якщо виділено фразу — обробляти як фразу (part_of_speech: "phrase").
- Таймаут, обробка помилок (немає мережі, 401, 429, 5xx). Якщо мережі немає, слово потрапляє в чергу «очікує обробки» і обробляється пізніше автоматично або кнопкою «Повторити».

## Модель даних і зберігання

- Один файл: `~/Library/Application Support/VocabApp/dictionary.json`.
```json
  {
    "schemaVersion": 1,
    "exportedAt": "2026-10-13T10:00:00Z",
    "entries": [
      {
        "id": "UUID", "languagePair": "en-uk", "word": "...", "lemma": "...",
        "partOfSpeech": "...", "transcription": "...", "translations": ["..."],
        "example": { "source": "...", "translation": "..." },
        "status": "ready | pending | failed",
        "createdAt": "ISO8601", "updatedAt": "ISO8601"
      }
    ]
  }
```
- `languagePair` закладається вже зараз (у майбутньому `it-uk`). Абстракція LanguagePair; промт залежить від пари; нова пара без переписування ядра.
- Атомарний запис (тимчасовий файл → заміна).
- Дублікати: нормалізація (lowercase, trim). Якщо вже є в тій самій мовній парі — не додавати, показати сповіщення.

## Перенесення на інший комп'ютер

- Експорт: NSSavePanel → `dictionary.json`.
- Імпорт: NSOpenPanel → режим:
  - **Об'єднати** (за замовчуванням): нові додаються, при конфлікті перемагає пізніший `updatedAt`;
  - **Замінити**: повна заміна (з підтвердженням і автоматичним бекапом поточного файлу).
- Валідація перед імпортом (schemaVersion, обов'язкові поля). Невалідний файл не ламає словник, показує зрозумілу помилку.
- Звіт: «Додано X, оновлено Y, пропущено Z».

## Головне вікно

- Список: слово, транскрипція, переклад, приклад.
- Пошук (за словом і перекладом), сортування (дата / алфавіт).
- Редагування і видалення.
- Ручне додавання слова.
- Озвучення (`AVSpeechSynthesizer`, англійський голос).
- Позначка `pending` / `failed` і кнопка «Повторити».
- Settings: API-ключ, модель, автозапуск, експорт/імпорт.

## Етапи та критерії приймання

**M1 — Каркас і зберігання**: project.yml, збірка з терміналу; модель даних, сервіс зберігання (читання/атомарний запис), головне вікно зі списком, ручне додавання/видалення/редагування. Тести: серіалізація/десеріалізація, атомарний запис, нормалізація і дублікати.

**M2 — Claude API**: клієнт API, Keychain, Settings; парсинг і валідація, повтор при невалідному JSON, черга pending. Тести: парсинг валідних/невалідних відповідей, HTTP-помилки (мок `URLProtocol`), ключ ніколи не в логах.

**M3 — Services**: пункт «Додати в словник» у Services у Safari, Chrome, TextEdit; слово додається, приходить сповіщення. Тести: обробник Services з тестовим pasteboard + чекліст ручної перевірки (/Applications, перший запуск, `/System/Library/CoreServices/pbs -update`, 3 програми).

**M4 — Експорт/імпорт**: обидва режими, бекап, валідація, звіт. Тести: merge з конфліктами за `updatedAt`, невалідний файл, порожній файл, інший schemaVersion.

**M5 — Полірування**: menu bar, автозапуск, озвучення, пошук і сортування. `README.md`: збірка, встановлення, активація в Services (System Settings → Keyboard → Keyboard Shortcuts → Services), перенесення словника.

## Загальні правила

- Не вигадувати неіснуючі API; невизначеність щодо macOS API — у `PROGRESS.md`.
- Не переходити до наступного етапу без PASS від Judge (макс. 3 ітерації на етап).
- Користувач дозволив не чекати його підтвердження: неоднозначності вирішуються розумним рішенням і фіксуються в `PROGRESS.md`.
