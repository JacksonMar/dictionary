# M3 — ручна перевірка (Services «Додати в словник»)

Середовище: macOS 13+ (**записати версію**: `sw_vers`), Xcode 15+, XcodeGen; реальний Anthropic API-ключ уже збережено
в «Налаштування…» (див. M2). Браузери: Safari, Google Chrome (записати версії); TextEdit; за бажанням — Preview, Notes.

Перевіряє невизначеності U1 (NSPortName), U2 (чи потрібне ручне вмикання), U4 (реєстрація через `pbs`),
U5 (холодний запуск через Services), U6 (Chrome / PDF), U7 (сповіщення при ad-hoc підписі).
Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили (для U1–U7 — обов'язково з коментарем).

Шляхи: словник — `~/Library/Application Support/VocabApp/dictionary.json`; логи — subsystem `com.vocabapp.VocabApp`.

## B. Виклик сервісу в різних застосунках

Для кожного застосунку: виділити текст → ПКМ → Services (Служби) → «Додати в словник» (або меню застосунку →
Services → «Додати в словник»). Перевірити сповіщення (банер) **і** рядок останнього результату в меню VocabApp
(menu bar → текст під пунктами), і запис у вікні «Словник».

| # | Застосунок / крок | Очікуваний результат | Safari | Chrome | TextEdit | Preview (PDF) / Notes |
|---|---|---|---|---|---|---|

| # | Крок | Очікуваний результат | Результат |
