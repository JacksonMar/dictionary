# M6 — ручна перевірка (таблиця, пагінація, тема, логи)

Джерело: `docs/reports/2026-10-14-mac-test-report.md` (P1–P5, UX-побажання). Середовище: реальний Mac, **записати**
`sw_vers` (бажано macOS 13 і новіша); Release-збірка за README, встановлена в `/Applications`; API-ключ збережено.

Підготовка для B: словник з ≥ 60 записів — імпортувати тестовий файл (Налаштування → «Імпортувати…» →
«Об'єднати»), напр. згенерований експортом іншого словника або вручну складений JSON зі `schemaVersion: 1`.
Серед записів мають бути один `pending` і один `failed` (напр. додати слово без мережі; слово з невірним ключем).

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили.
