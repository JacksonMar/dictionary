# M5 — ручна перевірка (menu bar, автозапуск, озвучення, пошук і сортування, README)

Середовище: macOS 13 (обов'язково, U12) і, за можливості, 14/15 (**записати версії**: `sw_vers -productVersion`);
Release-збірка за README, встановлена в `/Applications`; API-ключ збережено; у словнику ≥ 5 записів
(серед них `run — бігти`, фраза `give up`, один `pending` або `failed`).

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили.

## A. Запуск і menu bar (U12)

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| A1 | Вийти з VocabApp; `open /Applications/VocabApp.app` | Лише іконка в menu bar; **жодне вікно не відкривається** (ні «Словник», ні «Налаштування»), іконки в Dock немає. Записати для кожної версії macOS | |
| A2 | Клік по іконці | Меню: (останній результат Services, якщо був), «Відкрити словник», «Повторити очікувані (N)» (лише якщо є pending/failed), «Налаштування…», «Вийти» | |
| A3 | «Відкрити словник», коли активна інша програма (Safari) | Вікно «Словник» відкривається **поверх** Safari і отримує фокус | |
| A4 | Закрити вікно; знову «Відкрити словник» | Вікно відкривається знову (одне, не дубль) | |
| A5 | «Налаштування…» | Вікно «Налаштування» поверх інших, з фокусом | |
| A6 | «Повторити очікувані (N)» | N = кількість pending+failed; після обробки пункт зникає або N зменшується; під час обробки пункт неактивний | |
| A7 | Додати слово через Services, відкрити меню | Перший рядок — результат («Додано: …») | |
| A8 | Видалити ключ у Налаштуваннях, відкрити меню | Пункт «API-ключ не задано — відкрити налаштування» відкриває Налаштування | |
| A9 | «Вийти» | Застосунок завершується, іконка зникає | |
| A10 | Холодний запуск через Services (як M3 C5) | Вікна не відкриваються; слово додано | |
| A11 | Повторити A1–A5 на macOS 14/15 (якщо доступно) | Та сама поведінка; версії записати в «Результати» | |

## B. Автозапуск (U8)

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| B1 | Налаштування → «Запускати при вході в систему» → увімкнути | Тумблер увімкнений. Якщо macOS вимагає підтвердження — текст про дозвіл і кнопка «Відкрити Login Items». Записати фактичний стан (U8) | |
| B2 | (якщо є) «Відкрити Login Items» | Відкривається System Settings → General → Login Items; VocabApp у списку; дозволити | |
| B3 | Повернутися у вікно Налаштувань | Стан оновився (повідомлення про дозвіл зникло) | |
| B4 | Вийти з облікового запису й увійти знову | VocabApp запущено автоматично (іконка в menu bar), вікна не відкриваються | |
| B5 | Вимкнути тумблер; перелогін | VocabApp не запускається; у Login Items його немає | |
| B6a | Вимкнути VocabApp у System Settings → Login Items вручну; відкрити Налаштування застосунку | Тумблер показує вимкнений стан (стан перечитується з системи, а не з `UserDefaults`) | |
| B6 | Запустити копію з `build/Build/Products/Release/` (не з /Applications) і увімкнути автозапуск | Записати поведінку: помилка під тумблером / `requiresApproval` / «Система не знайшла застосунок…» (U8) | |

| # | Крок | Очікуваний результат | Результат |

| D3 | `cafe` при записі `café` (або `naive` / `naïve`) | Знайдено (без урахування діакритики) | |
| D4 | Пошук за лемою: додати `went` (лема `go`), шукати `go` | Знайдено `went` | |
| D5 | `qwertyzz` | «Нічого не знайдено за запитом «qwertyzz».»; очистити поле — повний список | |
| D6 | Сортування «Спершу нові» / «Спершу старі» / «За алфавітом» | Порядок відповідає; алфавіт без урахування регістру | |
| D6a | Пошук `run` + кожне з трьох сортувань | Фільтр зберігається, змінюється лише порядок | |
| D6b | Поле пошуку лише з пробілів | Повний список (як порожній запит) | |
| D6c | Закрити й відкрити вікно «Словник» | Записати, чи зберігаються запит і сортування (очікувана поведінка не специфікована — лише зафіксувати) | |
| D7 | Під час пошуку додати слово через Services, що відповідає запиту | З'являється в результатах без перезапуску | |
