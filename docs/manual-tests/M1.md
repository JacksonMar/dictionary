# M1 — ручна перевірка (каркас і зберігання)

Середовище: macOS 13+ (записати версію), Xcode 15+, XcodeGen.

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| 1 | `xcodegen generate && xcodebuild build -project VocabApp.xcodeproj -scheme VocabApp -destination 'platform=macOS' -derivedDataPath build CODE_SIGN_IDENTITY=-` | Збірка успішна | |
| 2 | Запустити `build/Build/Products/Debug/VocabApp.app` | У menu bar з'являється іконка книги; іконки в Dock немає (LSUIElement) | |
| 3 | Меню → «Відкрити словник» | Відкривається вікно «Словник», застосунок активний; порожній словник показує підказку | |
| 4 | «+» → заповнити слово `run`, переклади `бігти, керувати`, транскрипцію, приклад → «Додати» | Запис з'являється у списку з усіма полями | |
| 5 | «+» → `Run ` (з пробілом) → «Додати» | Помилка ««run» вже є в словнику», другий запис не створено | |
| 6 | «+» → слово без перекладу | Помилка «Додайте хоча б один переклад» | |
| 7 | Олівець (або контекстне меню → «Редагувати») → змінити переклад → «Зберегти» | Зміна видна в списку | |
| 8 | Кошик → підтвердити видалення | Запис зник | |
| 9 | «Вийти», запустити знову, відкрити словник | Дані збережено | |
| 10 | `cat ~/Library/Application\ Support/VocabApp/dictionary.json` | `schemaVersion: 1`, `exportedAt`, `entries` з ключами `id, languagePair, word, lemma, partOfSpeech, transcription, translations, example{source,translation}, status, createdAt, updatedAt`; дати ISO8601 (`…Z`); у каталозі немає `.tmp`-файлів | |
| 11 | Вийти, записати в `dictionary.json` сміття (`echo garbage > …/dictionary.json`), запустити, відкрити словник | Попередження про пошкоджений файл; файл перенесено в `Backups/dictionary-corrupted-*.json`; словник порожній | |
| 12 | Вийти, змінити `schemaVersion` на `2`, запустити, відкрити словник | Помилка про новішу версію схеми; файл не змінено | |
| 13 | Перевірити, чи вікно «Словник» **не** відкривається саме при запуску (U12) | Лише іконка в menu bar | |
| 14 | Додати `walk`, потім відредагувати його слово на `RUN` → «Зберегти» | Помилка ««run» вже є в словнику», запис `walk` не змінився | |
| 15 | «+» → слово `don’t` (кривий апостроф), потім ще раз `don't` | Другий раз — помилка про дубль | |
| 16 | `xcodebuild test -project VocabApp.xcodeproj -scheme VocabApp -destination 'platform=macOS' -derivedDataPath build CODE_SIGN_IDENTITY=-` | `AppModelTests` і `AppSmokeTests` зелені; `~/Library/Application Support/VocabApp/dictionary.json` після тестів не змінився (порівняти `shasum` до/після) | |

Автоматично покрито (не потребує ручної перевірки): серіалізація, атомарний запис, бекап зіпсованого файлу,
новіша `schemaVersion`, нормалізація й дублікати — `swift test` (`Tests/VocabCoreTests`); ручне
додавання/редагування/видалення/дубль у `AppModel` — `App/Tests/AppModelTests.swift`.
