# M7 — ручна перевірка (перемикач EN | IT, автовизначення мови, економія токенів)

Джерело: запит користувача 2026-10-14; дизайн — `ARCHITECTURE.md` §3.2, §7.7, §8.4, D21–D30.
Середовище: реальний Mac, **записати** `sw_vers`; Release-збірка за README, встановлена в `/Applications`;
реальний API-ключ збережено. Логи:
`log stream --predicate 'subsystem == "com.vocabapp.VocabApp" AND category == "claude"' --info`.
Кількість запитів рахувати за рядками `Claude request ok` / `Claude request failed`.

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили.

## B. Доповнення старих записів (U15)

Підготовка: словник з ≥ 20 англійських записів без італійських даних (напр. імпорт експорту M6).

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| B1 | Перемкнути на IT | Поки йде прохід — «Доповнення італійською…»; у Console `Variant backfill started: trigger=displaySwitch language=it eligible=N` і `… finished … requests=ceil(N/15)` (для 20 → `requests=2`); у логах немає `max_tokens`/400 | |
| B2 | Таблиця в режимі IT | Італійські слова, IPA, українські переклади, приклади італійською | |
| B3 | EN → IT ще раз; потім перезапуск застосунку в режимі IT | Нових `Claude request` немає (`requests=0` або `eligible=0`) | |
| B4 | `jq '.entries[0].variants' ~/Library/Application\ Support/VocabApp/dictionary.json` | Є `variants.it` зі `status: "ready"` і `sourceKey`; `schemaVersion` = 1 | |
| B5 | Пошук у режимі IT за італійським словом; сортування «За алфавітом» | Знаходить запис; порядок — за італійськими словами | |
