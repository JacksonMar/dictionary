# I2b — Голосове введення (UI)

Джерело: `IOS_PLAN.md` DI10–DI13, DI17, §2 (`Mobile/Sources/Voice/*`), §4 (голос, глибокі посилання,
конкурентність), §5 (`AddWordSheet`, `VoiceCaptureView`), §7 «I2b»; рішення користувача **iU15 = (а)**: розпізнане
слово **завжди** підтверджується кнопкою «Add» (автододавання немає, КП I2b.4 не застосовується).

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили. Помилки Xcode/`xcodebuild` — **дослівно** (перед
вставкою замінити Team ID на `<TEAM_ID>`, Apple ID — на `<APPLE_ID>`). **API-ключ ніколи не вставляти в звіт.**

Що в I2b **немає** (не баг): автододавання без підтвердження, Siri/Shortcuts і віджет (I4 — посилання
`vocabapp://voice` поки відкривається лише вручну), «Поділитися» (I3), експорт/імпорт (I5).

Економія токенів: слово голосом — як введене: нове — **1** запит (мова мовлення йде підказкою в тому самому
промті, DI13), дубль — **0**, порожнє розпізнавання — **0** (нічого не надсилається). Лічильник — Console.app, як у
`I1b.md` розділ 0 (`subsystem:com.vocabapp.VocabApp category:claude`, рядки `Claude request ok/failed`).

## 0. Промпт для Claude Code на Mac

```
git pull && xcodegen generate
# macOS-регресія ОБОВ'ЯЗКОВО (ядро змінювалось в I2a: Entry.languageHint, AddWordUseCase/PromptBuilder; в I2b — ключі voice.*):
xcodebuild test -project VocabApp.xcodeproj -scheme VocabApp -destination 'platform=macOS' CODE_SIGN_IDENTITY=-
xcodebuild test -project VocabApp.xcodeproj -scheme VocabMobile -destination 'platform=iOS Simulator,name=iPhone 16'
# якщо в I0 симулятор потребував План Б (iU8) — додати: DEVELOPMENT_TEAM= CODE_SIGNING_ALLOWED=NO
# пристрій: Xcode → схема VocabMobile → обраний iPhone → Run, далі розділи 2–9 цього файлу
```

Це перша збірка iOS-коду в Xcode після I0–I2a (перевірку на Mac відкладено) — помилки компіляції в `Mobile/Sources`
очікувані; повернути їх **дослівно** (файл:рядок:повідомлення), разом з усіма попередженнями з `Mobile/Sources/Voice/*`.

## 3. Слова (пристрій; мережа є)

Для кожного рядка: живий частковий текст під час мовлення; автозупинка приблизно через 1,5 с після того, як
замовкли; редаговане поле з розпізнаним текстом; «Add» → картка (заголовок і текст, як у сповіщеннях macOS) з
«Speak», «Again», «Done». Записати: що розпізнано, чи довелось правити, що показала картка, кількість запитів.
Перед розділом видалити з словника `run`, `casa`/`house`, `perché`, `come`, `take off`, якщо вони є.

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| W1 | **EN**, сказати `run` → «Add» | Поле `run` (можливо `Run` — регістр не важливий); картка «Added…» з перекладами; **1** запит | |
| W2 | **IT**, сказати `casa` | Поле `casa`; «Add» → **1** запит (або **0** і картка «Already in the dictionary», якщо є `house` з італійською версією `casa`, D26); у словнику — італійська версія запису | |
| W3 | **IT**, сказати `perché` | Поле `perché` **з наголосом** (якщо без — виправити в полі й записати); «Add» → італійське слово, **1** запит | |
| W4 | **IT**, сказати `come` | Поле `come`; «Add» → запис італійського `come` (переклад «як»), **1** запит. Без підказки мови (DI13) це було б англійське «приходити» | |
| W5 | **EN**, сказати `come` | За D26 — найімовірніше дубль (ключ `come` уже є в італійській версії), **0** запитів; записати точний текст картки (обмеження з IOS_PLAN §3.2) | |
| W6 | **EN**, сказати `take off` | Поле `take off` (фраза з двох слів); «Add» → **1** запит | |
| W7 | Сказати щось, у полі виправити текст (напр. `runn` → `run`), «Add» | Додається виправлений текст (дубль `run` → **0** запитів) | |
| W8 | Після зупинки, поки видно «Finishing recognition…», нічого не чіпати | Текст у полі може уточнитись (остаточний результат); якщо встигли змінити поле — уточнення його **не** перезаписує | |
| W9 | Під розпізнаним текстом зʼявились чипи варіантів (не завжди) | Дотик підставляє варіант у поле (опційно, не критерій) | |
| W10 | Двічі швидко натиснути «Add» | Один запис, **1** запит | |

## 5. Без мережі (on-device / сервер, DI12)

Чи є офлайн-модель для мови: iPhone Settings → General → Keyboard → Dictation Languages (моделі завантажуються
системою; для `it-IT` на деяких iPhone їх немає — iU4). Позначка «…audio is recognized by Apple servers» під полем
означає, що для мови моделі на пристрої немає.

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| O1 | Мережа є; **EN** → слухати | Записати: чи видно позначку серверного розпізнавання (очікувано — немає, `en-US` має модель на пристрої) | |
| O2 | Мережа є; **IT** → слухати | Записати: позначка є / немає (= чи є on-device для `it-IT`) | |
| O3 | Авіарежим; мова **з** моделлю на пристрої (зазвичай EN) → сказати `tree` | Розпізнається офлайн; «Add» → запис `pending` (немає мережі для Claude), картка «Saved to the queue…»; після вимкнення авіарежиму й повернення в застосунок — ready (`trigger=foreground`) | |
| O4 | Авіарежим; мова **без** моделі на пристрої (з O2) → мікрофон | Одразу червоний текст «No internet connection, and there is no offline speech model…» і поле для ручного введення; ввести слово → «Add» → `pending` | |
| O5 | Вимкнути мережу **під час** серверного слухання (O2 без моделі) | Або вже розпізнаний текст у полі, або помилка з полем ручного введення; застосунок не зависає | |

## 7. Глибоке посилання `vocabapp://voice` (DI10, §4)

Пристрій: ввести посилання в адресний рядок Safari → «Open in "VocabApp"?» → Open (або нотатка з посиланням).
Симулятор: `xcrun simctl openurl booted "vocabapp://voice?lang=it"`.

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| D1 | Дозволи надано; застосунок закритий; `vocabapp://voice` | Застосунок відкривається, аркуш «New Word» і **одразу слухає** (червона кнопка), мова — остання вибрана; клавіатура не зʼявляється | |
| D2 | `vocabapp://voice?lang=it` | Слухає з **IT**. Закрити аркуш, відкрити «+»: перемикач — попередня збережена мова (мова з посилання діє лише на цей сеанс) | |
| D3 | Аркуш уже відкрито (стан результату) → `vocabapp://voice` | Аркуш лишається, починається нове слухання | |
| D4 | `vocabapp://voice?lang=de` | Як D1 (невідома мова → остання вибрана) | |
| D5 | Дозвіл мікрофона вимкнено в Settings → `vocabapp://voice` | Аркуш із червоним текстом і «Open Settings» (без слухання) | |
| D6 | Щойно встановлений застосунок (дозволів не питали) → `vocabapp://voice` | Аркуш у стані «Tap the microphone…» — системні запити зʼявляються лише після дотику до мікрофона | |
| D7 | `vocabapp://add` | Звичайний аркуш, поле введення у фокусі | |
