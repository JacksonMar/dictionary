# M4 — ручна перевірка (експорт / імпорт словника)

Середовище: macOS 13+ (**записати версію**: `sw_vers -productVersion`), збірка з M3 (Debug або Release,
записати commit). Бажано мати другий обліковий запис macOS («інший комп'ютер») або другий Mac.
API-ключ не обов'язковий (pending-записи просто лишаться в черзі).

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили (для ❌ — скриншот і текст повідомлення).

Шляхи: словник — `~/Library/Application Support/VocabApp/dictionary.json`;
бекапи — `~/Library/Application Support/VocabApp/Backups/`. Для зручності:

```sh
APPDIR=~/Library/Application\ Support/VocabApp
```

## A. Підготовка

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| A1 | Запустити VocabApp. Додати вручну (або через Services) щонайменше 4 записи: `run` (ready), `give up` (фраза), `serendipity`, і один pending (вимкнути Wi-Fi → додати `ephemeral` через «Заповнити через Claude» → увімкнути Wi-Fi пізніше) | У вікні «Словник» 4+ записи, один з позначкою pending | |
| A2 | `python3 -m json.tool "$APPDIR/dictionary.json" \| head -30`; `ls -la "$APPDIR/Backups" 2>/dev/null` | Валідний JSON, `schemaVersion: 1`; записати кількість записів N = `grep -c '"id"' "$APPDIR/dictionary.json"`; каталогу Backups нема або в ньому лише старі файли (записати їх) | |

| # | Крок | Очікуваний результат | Результат |

| B4 | `python3 -m json.tool ~/Desktop/dictionary.json \| head -40`; `grep -c '"id"' ~/Desktop/dictionary.json` | JSON з відступами й відсортованими ключами; `"schemaVersion" : 1`; `"exportedAt"` — поточний час UTC (формат `2026-10-13T10:00:00Z`); кількість `"id"` = N; у записах є `word`, `translations`, `status`, `createdAt`, `updatedAt`; pending-запис має `"status" : "pending"` і порожній `translations` | |

| B7 | `grep -c 'sk-ant' ~/Desktop/dictionary.json` | `0` (ключ API не потрапляє в експорт) | |

## C. Імпорт на «іншому комп'ютері»

Варіант 1 (рекомендовано): скопіювати `~/Desktop/dictionary.json` у `/Users/Shared/`, увійти в **другий
обліковий запис** macOS, встановити туди той самий `VocabApp.app` (або запускати з `/Applications`).
Варіант 2 (той самий користувач): вийти з VocabApp, `mv "$APPDIR/dictionary.json" ~/Desktop/dictionary-original.json`,
запустити VocabApp — словник порожній.

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| C1 | На «іншому комп'ютері» відкрити «Налаштування…» → «Імпортувати…» | NSOpenPanel «Імпорт словника», кнопка «Імпортувати», можна вибрати лише один `.json` файл (не теки) | |
| C2 | У панелі «Скасувати» | Нічого не відбувається, діалогів немає | |
| C3 | «Імпортувати…» → вибрати `dictionary.json` | Діалог «Імпорт словника» з кнопками «Об'єднати» (за замовчуванням, Enter), «Замінити…», «Скасувати» і поясненням обох режимів | |
| C4 | «Скасувати» в діалозі режиму | Діалог закривається; словник не змінився | |
| C5 | Знову вибрати файл → «Об'єднати» (або Enter) | Алерт «Імпорт завершено»: «Додано N, оновлено 0, пропущено 0» | |
| C6 | Відкрити «Словник» | Усі N записів з тими самими словами, перекладами, транскрипціями, прикладами; pending-запис pending (з ключем — обробляється чергою і стає ready) | |
| C7 | `grep -c '"id"' "$APPDIR/dictionary.json"` на цьому комп'ютері | = N | |
| C8 | Ще раз імпортувати той самий файл у режимі «Об'єднати» | «Додано 0, оновлено 0, пропущено N» + список причин «…: у словнику та сама або новіша версія» (не більше 10 рядків, далі «…та ще K»); записів не побільшало | |
| C9 | Варіант 2: після перевірки повернути оригінал: вийти з VocabApp, `mv ~/Desktop/dictionary-original.json "$APPDIR/dictionary.json"` | Оригінальний словник на місці після перезапуску | |

## D. Merge з конфліктами

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| D1 | На комп'ютері A відредагувати переклад `run` (напр. додати «керувати»), зберегти. Експортувати в `a.json` | — | |
| D2 | На комп'ютері B (після C) відредагувати переклад `serendipity`, додати нове слово `resilient`. Імпортувати `a.json` → «Об'єднати» | Звіт «Додано 0, оновлено 1, пропущено N-1» (оновлено `run`, бо на A новіша зміна); `serendipity` лишився з редагуванням B (новіша локальна версія); `resilient` на місці | |
| D3 | У `a.json` вручну змінити слово `give up` → `Give Up` і `id` на будь-який інший UUID (`uuidgen`), `updatedAt` на майбутню дату. Імпортувати → «Об'єднати» | Запис оновлено (збіг за словом без урахування регістру), нового дубля немає; id лишився локальний | |

## E. Replace з підтвердженням і бекапом

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| E1 | `shasum "$APPDIR/dictionary.json"`; `ls "$APPDIR/Backups"` | Записати хеш H і список файлів | |
| E2 | «Імпортувати…» → файл з 1–2 записами (напр. змінений `a.json`) → «Замінити…» | Алерт «Замінити словник?» з текстом «Поточний буде збережено в Backups.» і кнопками «Замінити» (destructive) / «Скасувати» | |
| E3 | «Скасувати» | Словник не змінено (`shasum` = H), нового файлу в Backups немає | |
| E4 | Повторити E2 → «Замінити» | Алерт «Імпорт завершено»: «Додано K, оновлено 0, пропущено 0»; у вікні «Словник» лише записи з файлу | |
| E5 | `ls -la "$APPDIR/Backups"` | Новий файл `dictionary-backup-yyyyMMdd-HHmmss.json` (час **UTC**, може відрізнятися від місцевого); `shasum` бекапу = H | |
| E6 | Відновлення з бекапу: вийти з VocabApp, `cp "$APPDIR/Backups/dictionary-backup-<stamp>.json" ~/Desktop/restore.json`, запустити, «Імпортувати…» → `restore.json` → «Замінити» | Повернувся попередній словник (з'явився ще один бекап) | |
| E7 | Ротація (за бажанням): виконати «Замінити» 11+ разів (з інтервалом ≥ 1 с) | У Backups не більше 10 файлів `dictionary-backup-*`; найстаріші видалено; файли `dictionary-corrupted-*` не чіпаються | |

## F. Невалідні файли (словник не змінюється)

Перед кожним кроком записати `shasum "$APPDIR/dictionary.json"`; після — хеш має збігтися, у Backups нічого не
з'явилося (і в режимі «Замінити» також — помилка до бекапу).

| # | Файл (створити в Terminal) | Очікуваний текст помилки (алерт «Не вдалося імпортувати») | Результат |
|---|---|---|---|
| F1 | `: > ~/Desktop/empty.json` (0 байтів) | «Файл порожній. Словник не змінено.» | |
| F2 | `printf '  \n\n ' > ~/Desktop/spaces.json` | «Файл порожній. Словник не змінено.» | |
| F3 | `echo 'hello' > ~/Desktop/text.json` | «Файл не є словником у форматі JSON. Словник не змінено.» | |
| F4 | `echo '[]' > ~/Desktop/array.json` | «Файл не є словником у форматі JSON. Словник не змінено.» | |
| F5 | `echo '{"entries":[]}' > ~/Desktop/nover.json` | «У файлі немає коректного поля schemaVersion — це не файл словника. Словник не змінено.» | |
| F6 | `echo '{"schemaVersion":2,"entries":[]}' > ~/Desktop/v2.json` | «Непідтримувана версія схеми файлу (2); підтримується версія 1. Словник не змінено.» | |
| F7 | `echo '{"schemaVersion":1}' > ~/Desktop/noentries.json` | «У файлі немає списку записів (entries). Словник не змінено.» | |
| F8 | Скопіювати `dictionary.json` з B3, у першому записі видалити `"word"`, у другому `"id"` замінити на `"123"`; імпорт «Об'єднати» у **порожній** словник | Імпорт успішний: «Додано N-2, оновлено 0, пропущено 2» + «• Запис #1: відсутнє поле word», «• Запис #2: некоректне поле id» | |
| F9 | `echo '{"schemaVersion":1,"entries":[]}' > ~/Desktop/zero.json` → «Об'єднати» | «Додано 0, оновлено 0, пропущено 0»; словник не змінено | |
| F10 | Файл без прав читання: `cp ~/Desktop/v2.json ~/Desktop/locked.json && chmod 000 ~/Desktop/locked.json` → імпорт | «Не вдалося прочитати файл: … Словник не змінено.» (записати точний текст — див. зауваження про подвійну крапку); `chmod 644` після перевірки | |
