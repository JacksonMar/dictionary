# I5 — Експорт/імпорт, полірування, README

Джерело: `IOS_PLAN.md` §5 (Налаштування → дані), §6 (підпис), §7 «I5», §9 (розходження з Mac); `ARCHITECTURE.md` §10
(merge/replace, бекап перед заміною, D1, D13, варіанти M7); зауваження Judge до плану: **AirDrop — через «Файли» →
«Поділитися»**.

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили. Помилки Xcode/`xcodebuild` — **дослівно** (перед
вставкою замінити Team ID на `<TEAM_ID>`, Apple ID — на `<APPLE_ID>`). **API-ключ ніколи не вставляти в звіт.**
Вміст `dictionary.json` у звіт не вставляти повністю — лише потрібні рядки (`schemaVersion`, окремий запис).

Як це працює (щоб розуміти очікування):
- **Експорт** (⚙︎ Settings → **Sync with Mac** → **Export to Files…**): знімок словника → `dictionary.json` (схема v1,
  той самий формат і енкодер, що на macOS; варіанти IT і `languageHint` — як є) → системне вікно «Зберегти у Файли»
  (`fileExporter`). Після збереження — алерт «Dictionary exported / Entries: N. File: dictionary.json» + підказка
  про AirDrop. **AirDrop прямо з VocabApp немає:** спершу зберегти у «Файли», потім у «Файлах» відкрити файл →
  «Поділитися» → AirDrop.
- **Імпорт** (**Import from Files…**): вибір `.json` у «Файлах» (`fileImporter`) → файл **копіюється** в тимчасову
  папку застосунку (доступ security-scoped лише на час копіювання; I6: копіювання — у координованому читанні
  `NSFileCoordinator`, тож ще не завантажений файл з iCloud Drive спершу завантажується) → діалог «Import Dictionary»: **Merge** (за
  замовчуванням) / **Replace…** → для Replace — алерт «Replace the dictionary? The current dictionary will be saved to
  Backups.» → звіт «Added X, updated Y, skipped Z» + перші 5 причин пропуску. Імпортовані `pending` — **один** прохід
  черги одразу після імпорту (1 запит на слово). Невалідний файл ніколи не змінює словник.
- **Merge (D1):** збіг за `id`, інакше за англійським ключем слова; перемагає пізніший `updatedAt`; імпортований
  `pending/failed` не перезаписує локальний `ready`; італійські версії об'єднуються (ready перемагає не-ready).
  **Видалення не синхронізуються.**
- Мова діалогів — мова інтерфейсу VocabApp (тексти ті самі, що на macOS: «Об'єднати», «Замінити…» тощо).

Лічильник запитів — Console.app, як у `I1b.md` розділ 0 (`subsystem:com.vocabapp.VocabApp category:claude`, рядки
`Claude request ok/failed`; тригер після імпорту — `Queue run started: trigger=imported`).

I6 (виправлено): банер «Words from Share» після помилки сховища показує в «Not saved yet: N» усі файли, що лишились
у inbox (раніше — 1); перевірка — `InboxIngestorTests.testStorageFailureKeepsFile` (`failed: 3`), ручного кроку немає
(див. `I3.md` розділ 7). Імпорт з iCloud Drive — крок A6. Порядок у `ImportFileStager.stage`: start → coordinate(copy)
→ stop; у тестах координатор прохідний (`PassthroughFileReadCoordinator`), тож журнал `MobileTransferTests` той самий
(start → copy → stop); справжній `NSFileCoordinator` — лише в `AppContainer.makeLive` (перевіряється тільки вручну, A6).

особливо про сигнатури `fileExporter`/`fileImporter`, `FileDocument` (`readableContentTypes`, `Sendable`),
