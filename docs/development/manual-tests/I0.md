# I0 — спайк підпису й можливостей (iPhone, Personal Team)

Джерело: `IOS_PLAN.md` §6, §7 «I0»; рішення користувача — `PROGRESS.md`, розділ «iOS».
Мета — закрити **iU1** (App Groups з Personal Team), **iU2** (ліміти застосунків/App ID), **iU3** (віджет без
спеціальних entitlements), **iU8** (симулятор) і вирішити План Б. Код спайка тимчасовий (замінюється в I1a);
`project.yml` і `Config/` лишаються.

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили. Усі помилки Xcode/`xcodebuild` — **дослівно**
(копіювати текст, а не переказувати; для Xcode — Report navigator → вибрати збірку → скопіювати рядок помилки).

## 1. Збірка й тести

```
git pull && xcodegen generate
xcodebuild test -project VocabApp.xcodeproj -scheme VocabApp -destination 'platform=macOS' CODE_SIGN_IDENTITY=-
xcodebuild test -project VocabApp.xcodeproj -scheme VocabMobile -destination 'platform=iOS Simulator,name=iPhone 16'
# якщо попередня команда впала на підписі (iU8), План Б для симулятора:
xcodebuild test -project VocabApp.xcodeproj -scheme VocabMobile -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```
(Якщо симулятора «iPhone 16» немає — `xcrun simctl list devices available` і підставити наявний iPhone.)

## 7. Рішення за результатом (фіксується в `PROGRESS.md`, `IOS_PLAN.md` §7 I0)

- **App Group не працює** (D4 ❌ або S3 ❌ через контейнер) → Share Extension **прибирається**; замість неї — ярлик
  Shortcuts «Отримати текст із листа Поділитися → Add to Dictionary» (intent з I4, App Group не потрібен). I3
  скорочується до ядра `Inbox/` або `Inbox/` теж відкладається.
- **Ліміт застосунків/App ID заважає** (D1/L2 ❌) → зменшуємо кількість таргетів: спершу прибираємо віджет (замінює
  ярлик Shortcuts на Home Screen / Action Button з `StartVoiceCaptureIntent`), далі — Share (як вище).
- **Симулятор потребує `CODE_SIGNING_ALLOWED=NO`** (T2 ❌, T3 ✅) → ця опція додається в усі промти для Mac
  (симуляторні команди); на симуляторі App Group тоді не гарантований — тести не повинні вимагати «App Group: OK».
- **Усе працює** → план без змін.

## 8. Нагадування

- Профіль Personal Team діє **7 днів**: потім — повторний Run з Xcode (дані зберігаються, якщо застосунок не
  видаляти).
- Не міняти `VOCAB_BUNDLE_ID_PREFIX` без потреби (ліміт нових App ID).
- Перед комітом: `git status` — `Config/Local.xcconfig` не має з'являтися; Linux-тест
  `RepositoryHygieneTests.testNoDevelopmentTeamCommitted` перевіряє, що Team ID не потрапив у `project.yml`/`Config/`.
