# I4 — App Intents (Siri / Швидкі команди) + віджет

Джерело: `IOS_PLAN.md` DI8, DI17, DI18, §2 (`Mobile/Sources/Intents/`, `Extensions/Widget/`), §4 (single-flight,
intent-и в процесі застосунку, паралельно з інжестом), §7 «I4», §8 (токени).

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили. Помилки Xcode/`xcodebuild` — **дослівно** (перед
вставкою замінити Team ID на `<TEAM_ID>`, Apple ID — на `<APPLE_ID>`). **API-ключ ніколи не вставляти в звіт.**

Як це працює (щоб розуміти очікування):
- **«Add to Dictionary»** (`AddToDictionaryIntent`) — виконується **у процесі застосунку без його відкриття**
  (`openAppWhenRun = false`, iU5): словник, Keychain і черга — ті самі, що в UI (DI8). Параметри: «Word» (текст) і
  «Language» (Auto / English / Italian; Italian/English — підказка мови для Claude, DI13). Відповідь — діалог Siri /
  Швидких команд мовою інтерфейсу VocabApp: «Added: house — дім, будинок», «Already in the dictionary: …»,
  «Saved to the queue: …» тощо (ті самі тексти, що й картка голосу). Нове слово — **1** запит, дубль — **0**.
  Якщо Claude відповідає довше **8 с** — відповідь «Saved “…”. It is still being translated — open VocabApp to see
  the result.»: запис уже `pending`, переклад завершується у фоні (або при наступному відкритті застосунку).
  На заблокованому iPhone система спершу просить розблокувати (`authenticationPolicy = .requiresAuthentication`).
- **«Add by Voice»** (`StartVoiceCaptureIntent`) — відкриває застосунок (`openAppWhenRun = true`) і аркуш додавання в
  режимі голосу; якщо дозволи мікрофона/мовлення вже є — **одразу слухає** (як `vocabapp://voice`). Параметр
  «Language»: Auto = остання вибрана мова голосу.
- **Готові фрази Siri** (App Shortcuts, англійською): «Add a word to VocabApp», «Add to VocabApp», «Translate with
  VocabApp» (Siri перепитає «Which word?»), «Add a word by voice to VocabApp», «Listen with VocabApp», «Start VocabApp
  voice input». Українські фрази видно лише в Швидких командах: Siri української не підтримує (iU7).
- **Віджет «Add by Voice»** — Home Screen (малий) і Lock Screen (круглий, прямокутний). Не оновлюється, не має App
  Group, не пише звук; дотик відкриває `vocabapp://voice` → аркуш одразу слухає. Назва й опис у галереї — мовою
  **системи** (не мовою інтерфейсу VocabApp — так задумано).

Лічильник запитів — Console.app, як у `I1b.md` розділ 0 (`subsystem:com.vocabapp.VocabApp category:claude`, рядки
`Claude request ok/failed`). Для intent-а окремого рядка немає: рахуємо `Claude request` під час виконання дії.

## 0. Промпт для Claude Code на Mac

```
git pull && xcodegen generate
# macOS-регресія ОБОВ'ЯЗКОВО (ядро змінилось: ключі L10n intent.*):
xcodebuild test -project VocabApp.xcodeproj -scheme VocabApp -destination 'platform=macOS' CODE_SIGN_IDENTITY=-
xcodebuild test -project VocabApp.xcodeproj -scheme VocabMobile -destination 'platform=iOS Simulator,name=iPhone 16'
# якщо в I0 симулятор потребував План Б (iU8) — додати: DEVELOPMENT_TEAM= CODE_SIGNING_ALLOWED=NO
# збірка всього (застосунок + Share + Widget) з метаданими App Intents:
xcodebuild build -project VocabApp.xcodeproj -scheme VocabMobile -destination 'generic/platform=iOS Simulator' 2>&1 | grep -E 'error|warning: .*(Intents|Widget|AppShortcuts|Localizable|ShareViewController|appintents|Metadata)'
# метадані App Intents і ресурси в бандлах:
APP=$(ls -d ~/Library/Developer/Xcode/DerivedData/VocabApp-*/Build/Products/Debug-iphonesimulator/VocabMobile.app | head -1)
ls "$APP/Metadata.appintents" && plutil -p "$APP/Metadata.appintents/extract.actionsdata" | grep -E '"identifier"|openAppWhenRun|authenticationPolicy|descriptionMetadata|description' | head -20
ls "$APP/en.lproj" "$APP/uk.lproj" "$APP/PlugIns/VocabWidget.appex/en.lproj" "$APP/PlugIns/VocabWidget.appex/uk.lproj"
plutil -p "$APP/Info.plist" | grep -A4 CFBundleURLTypes
# симулятор: віджет і deep link
xcrun simctl openurl booted 'vocabapp://voice?lang=it'
# пристрій: Xcode → схема VocabMobile → обраний iPhone → Run, далі розділи 2–7 цього файлу
```

Повернути **дослівно** (файл:рядок:повідомлення) усі помилки й попередження з `Mobile/Sources/Intents/*`,
`Extensions/Widget/Sources/*`, `Extensions/Share/Sources/ShareViewController.swift`,
`Mobile/Sources/{AppContainer,Router,VocabMobileApp}.swift`, а також усе, що пише крок метаданих App Intents
(`appintentsmetadataprocessor`, «Extract app intents metadata») — зокрема про `AppShortcuts.strings`,
`${applicationName}`, `parameterSummary`, `description`, `static let`.

## 8. Спостереження (заповнити текстом)

- **iU3** (entitlements для Personal Team): чи збирається й встановлюється застосунок з App Intents і віджетом без
  додаткових capabilities; чи з'явились готові команди в Shortcuts одразу після установки (або після першого запуску):
- **iU5** (intent у процесі застосунку): чи застосунок не відкривався під час K2/R1; чи встигає відповідь (час на око);
  чи траплялось «Saved… still being translated» за нормальної мережі:
- **iU7** (Siri і мови): що Siri розпізнає для англійських і для італійських слів; чи українські фрази впливають на
  Siri (очікувано — ні):
- Кнопка дії: модель iPhone, чи працює:
- Віджет: затримка від дотику до слухання (холодний / теплий старт):
