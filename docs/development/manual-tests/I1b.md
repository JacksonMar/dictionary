# I1b — CRUD, Claude, Налаштування/Keychain

Джерело: `IOS_PLAN.md` DI4, DI5, DI8, DI14, DI16–DI19, §4, §5, §7 «I1b», §8. Share Extension і віджет — ще спайкові
(I3/I4); голосу немає (I2b); експорту/імпорту немає (I5).

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили. Помилки Xcode/`xcodebuild` — **дослівно** (перед
вставкою замінити Team ID на `<TEAM_ID>`, Apple ID — на `<APPLE_ID>`). **API-ключ ніколи не вставляти в звіт.**

Що в I1b **немає** (не баг): мікрофон і голос, «Поділитися» → словник, Siri/Shortcuts, експорт/імпорт, вибір теми,
кнопка «Доповнити італійською (N)» (на iPhone — автодоповнення в режимі IT і «Оновити італійський» для одного запису),
таймер повторів (pending-записи повторюються при поверненні застосунку на передній план і жестом «потягнути вниз»).

Економія токенів (перевіряється нижче): нове слово — **1** запит, дубль — **0**, ручне додавання/редагування — **0**,
«Оновити італійський» — **1**, перемикання на IT — `ceil(N/15)` запитів для N старих записів без італійської версії,
повторне перемикання — 0. Лічильник запитів — Console.app (розділ 0).

## 0. Як рахувати запити

Mac → Console.app → ліворуч симулятор або iPhone → пошук `subsystem:com.vocabapp.VocabApp category:claude` → Start.
Кожен запит до Claude — рядок `Claude request ok: …` або `Claude request failed: …`. Тригери черги — рядки
`Queue run started: trigger=…`. У логах не має бути ні слів, ні ключа (лише `sk-ant-[REDACTED]`, якщо взагалі).
