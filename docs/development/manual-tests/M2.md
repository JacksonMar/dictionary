# M2 — ручна перевірка (Claude API, Keychain, Settings, черга)

Середовище: macOS 13+ (записати версію), зібраний `VocabApp.app` (див. M1, кроки 1–2), **реальний** Anthropic API-ключ
(далі `$KEY`; не вставляти його в цей файл, тікети чи чати). Перед початком: `export KEY='sk-ant-…'` у Terminal
лише для `grep`-перевірок, після перевірки — `unset KEY`.

Шляхи: словник — `~/Library/Application Support/VocabApp/dictionary.json`; Keychain service — `com.vocabapp.VocabApp`,
account — `anthropic-api-key`; логи — subsystem `com.vocabapp.VocabApp`, category `claude`.
