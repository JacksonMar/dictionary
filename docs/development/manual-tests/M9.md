# M9 — ручна перевірка (інтерфейс англійською та українською)

Джерело: запит користувача 2026-10-20; дизайн — `ARCHITECTURE.md` §15 M9, D32–D39 (README — M10, D40).
Середовище: реальний Mac, **записати** `sw_vers` і мову системи (System Settings → General → Language & Region,
перша в списку). Release-збірка наявними командами README, встановлена в `/Applications`; реальний API-ключ
збережено (крім кроків, де сказано інакше). Логи:
`log stream --predicate 'subsystem == "com.vocabapp.VocabApp"' --info`.

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили (для U20/U21 — точна поведінка).

Корисні команди:
- поточне значення налаштування: `defaults read com.vocabapp.VocabApp interfaceLanguage`;
- `AppleLanguages` у домені застосунку: `defaults read com.vocabapp.VocabApp AppleLanguages`;
- кількість екземплярів: `pgrep -lx VocabApp` (або Activity Monitor).

| # | Мова системи | Очікуваний результат | Результат |

## F. Невизначеності — записати фактичну поведінку

| # | Питання | Спостереження |
|---|---|---|
| U20 | Чи `AppleLanguages` у домені застосунку змінює системні рядки (панелі, стандартні меню) після перезапуску ad-hoc застосунку; чи надійний перезапуск через `/bin/sh` + `open` (скільки секунд, чи бували два екземпляри / жодного) | |
| U21 | Чи `ServicesMenu.strings` підхоплюється без перелогіну; чи ключем справді є `NSMenuItem.default`; чи системи без `uk` отримують `en.lproj` | |

## Автоматизовано (не повторювати вручну)

Ядро (Linux, `swift test`):
- `LocalizationTests` — усі ключі непорожні обома мовами, однакові плейсхолдери, без кирилиці в англійській
  таблиці, `.en` за замовчуванням (`AppLanguage.default`, `L10n.current`, `init(storedValue:)`), перемикання
  `setCurrent`, підстановка за один прохід, відсутній аргумент лишає токен.
- `HardcodedStringsScanTests` — кирилиця в рядкових літералах `Sources/VocabCore` і `App/Sources` лише в
  `Localization/`, `Languages/` і в оголошенні `PromptBuilder.retrySuffix` (quote-aware вирізання коментарів;
  англійські літерали не перевіряються — для цього пункт B).
- `LocalizedMessagesTests` — сповіщення, `ClaudeError`, помилки сховища/репозиторію/імпорту/Keychain,
  `FileErrorText`, звіт імпорту, пагінація, теми й сортування — обома мовами; українські тексти M8 не змінились.
- `SettingsStoreTests` — `interfaceLanguage`: default `.en`, збереження в `UserDefaults`, невідоме → `.en`.
- Наявні набори з українськими асертами фіксують мову через `pinInterfaceLanguage(.uk)` (D39).

Застосунок (macOS, `xcodebuild test`): `InterfaceLanguageTests` — `CFBundleDevelopmentRegion`/
`CFBundleLocalizations`, `ServicesMenu.strings` в `en.lproj`/`uk.lproj`, bootstrap, вибір мови → налаштування +
`AppleLanguages` (фейк), «Restart now» лише коли потрібно, фейковий relauncher і помилка, аргументи й обмеженість
скрипта перезапуску (виконується `/bin/sh` з копією скрипта без пауз), підписи мов відображення й заголовки вікон.
Вручну лишаються реальний перезапуск, системні рядки AppKit, меню Services і оновлення поверх M8.
