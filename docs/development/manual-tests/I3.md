# I3 — Share Extension + inbox

Джерело: `IOS_PLAN.md` DI6, DI7, DI9, DI15, DI18, §3.3 (Inbox API), §4 (single-flight `ingest()`, порядок на
старті / `.active`: `ensureLoaded → ingest → processAll(.foreground) → доповнення IT`), §7 «I3».

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили. Помилки Xcode/`xcodebuild` — **дослівно** (перед
вставкою замінити Team ID на `<TEAM_ID>`, Apple ID — на `<APPLE_ID>`). **API-ключ ніколи не вставляти в звіт.**
Слова, які ви ділили, у звіт вставляти можна (це не персональні дані), але не вставляйте приватні листування.

Як це працює (щоб розуміти очікування): лист «Поділитися» → **VocabApp** кладе текст файлом у спільну папку App
Group (`<App Group>/Inbox/<час>-<uuid>.json`) і показує «Saved — will be translated when you open VocabApp.».
Розширення **не** звертається до Claude, не читає Keychain і не пише словник (DI7). Застосунок при кожній
активації (`scenePhase == .active`) забирає файли: валідація (≤ 120 символів, ≤ 8 слів, є літери) → запис
`pending` → файл видаляється → **один** прохід черги (1 запит на нове слово) → банер «Words from Share» над
списком. Дубль — **0** запитів. Сповіщень немає (DI15): переклад з'являється лише після відкриття застосунку.

Мова листа «Поділитися»: розширення не бачить налаштувань застосунку (`UserDefaults` не спільні), тому тексти — за
**мовою системи** iPhone: українська серед бажаних мов вище англійської → українською, інакше англійською.
Мова інтерфейсу в налаштуваннях VocabApp на розширення **не** впливає (так задумано).

Що в I3 **немає** (не баг): фонової обробки inbox без відкриття застосунку (iU10), сповіщень, Siri/Shortcuts і
віджета (I4), експорту/імпорту (I5). Підказки мови з «Поділитися» немає: слово визначається як звичайне введене
(D25) — італійське `come` з листа «Поділитися» стане англійським.

Лічильник запитів — Console.app, як у `I1b.md` розділ 0 (`subsystem:com.vocabapp.VocabApp category:claude`, рядки
`Claude request ok/failed`; там само `Queue run started: trigger=inbox` і
`Inbox ingest finished: queued=… duplicates=… rejected=… failed=…` — лише лічильники, без слів). Лог розширення:
`subsystem:VocabShare category:share`, рядок `Share finished: saved|empty|appGroupUnavailable|inboxFull|storageFailed`.

## 0. Промпт для Claude Code на Mac

```
git pull && xcodegen generate
# macOS-регресія ОБОВ'ЯЗКОВО (ядро змінилось: Sources/VocabCore/Inbox/*, AppLanguage(preferredLanguages:), ключі share.*/inbox.*):
xcodebuild test -project VocabApp.xcodeproj -scheme VocabApp -destination 'platform=macOS' CODE_SIGN_IDENTITY=-
xcodebuild test -project VocabApp.xcodeproj -scheme VocabMobile -destination 'platform=iOS Simulator,name=iPhone 16'
# якщо в I0 симулятор потребував План Б (iU8) — додати: DEVELOPMENT_TEAM= CODE_SIGNING_ALLOWED=NO
# окремо зібрати розширення (перевіряє лінкування VocabCore у VocabShare з APPLICATION_EXTENSION_API_ONLY=YES):
xcodebuild build -project VocabApp.xcodeproj -scheme VocabMobile -destination 'generic/platform=iOS Simulator' 2>&1 | grep -E 'error|warning: .*(VocabShare|VocabCore|Share|Inbox)|duplication|not safe for use in application extensions'
# пристрій: Xcode → схема VocabMobile → обраний iPhone → Run, далі розділи 2–8 цього файлу
```

Повернути **дослівно** (файл:рядок:повідомлення) усі помилки й попередження з `Extensions/Share/Sources/*`,
`Mobile/Sources/Platform/InboxLocation.swift`, `Mobile/Sources/Views/{InboxBanner,EntryListView,AddWordSheet}.swift`,
`Mobile/Sources/{AppContainer,MobileAppModel}.swift`, а також будь-яке повідомлення про «linked as a static library by
… duplication of library code» чи «not safe for use in application extensions».

до цього числа.
