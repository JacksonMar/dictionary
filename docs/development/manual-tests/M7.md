# M7 — ручна перевірка (перемикач EN | IT, автовизначення мови, економія токенів)

Джерело: запит користувача 2026-10-14; дизайн — `ARCHITECTURE.md` §3.2, §7.7, §8.4, D21–D30.
Середовище: реальний Mac, **записати** `sw_vers`; Release-збірка за README, встановлена в `/Applications`;
реальний API-ключ збережено. Логи:
`log stream --predicate 'subsystem == "com.vocabapp.VocabApp" AND category == "claude"' --info`.
Кількість запитів рахувати за рядками `Claude request ok` / `Claude request failed`.

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили.

## Автоматизовано (не повторювати вручну)

Ядро (Linux, `swift test`): формат і сумісність з M6 (`EntryVariantCodingTests`), комбінований промт і розбір
(`CombinedPromptBuilderTests` у `PromptBuilderTests.swift`, `CombinedLookupParserTests`), рівно 1 запит на нове слово
(`TokenEconomyTests`), дублікати (`CrossLanguageDedupTests`), пакетний промт/розбір (`VariantPromptBuilderTests`,
`VariantBatchParserTests`), доповнення `ceil(n/15)`, 0 повторних запитів, поділ обрізаного пакета, помилки
(`VariantBackfillProcessorTests`), відображення/пошук (`EntryDisplayTests`, `EntryQueryTests`), імпорт/merge
(`VariantImportMergeTests`), налаштування/логи/сповіщення (`SettingsStoreTests`, `ProcessingTriggerTests`,
`NotificationTextTests`). Застосунок (macOS, `xcodebuild test`): `AppModelM7Tests`. Вручну лишаються UI, реальна
модель (якість, `max_tokens` — U15, U18), розміщення toolbar (U16), голос `it-IT` (U17), мережа й перезапуск.
