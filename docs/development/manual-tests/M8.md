# M8 — ручна перевірка (IT/QA-контекст перекладів)

Джерело: запит користувача 2026-10-16; дизайн — `ARCHITECTURE.md` §15 M8, D31.
Середовище: реальний Mac, **записати** `sw_vers`; Release-збірка за README, встановлена в `/Applications`;
реальний API-ключ збережено. Логи:
`log stream --predicate 'subsystem == "com.vocabapp.VocabApp" AND category == "claude"' --info`.
Кількість запитів рахувати за рядками `Claude request ok` / `Claude request failed`.

Кожен рядок «Результат» заповнити: ✅ / ❌ + що саме побачили (для U19 — переклади й приклад).

## B. Старі записи

Підготовка: до встановлення M8 зберегти копію `~/Library/Application Support/VocabApp/dictionary.json` (записи,
додані до M8, з італійськими версіями й без).

| # | Крок | Очікуваний результат | Результат |
|---|---|---|---|
| B1 | Запустити M8, відкрити словник у режимі EN, потім IT, потім перезапустити застосунок | Для записів, доданих до M8, нових `Claude request` немає (окрім доповнення тих, що й раніше були без італійської версії) | |
| B2 | Порівняти `dictionary.json` з копією (`translations`, `example`, `updatedAt`, `variants.it` готових записів) | Без змін | |
| B3 | Доповнити італійською запис без італійської версії (режим IT / кнопка «Доповнити італійською (N)») для IT-слова (напр. імпортоване `commit`) | Італійська версія — з IT/QA-перекладом першим і IT/QA-прикладом; англійські поля запису не змінилися | |

## Автоматизовано (не повторювати вручну)

Ядро (Linux, `swift test`): `DomainPromptTests` — інструкція IT/QA в промті пари й у пакетному промті, у
комбінованому промті рівно один раз, без інструкції промти дорівнюють M7, схеми й user-шаблони не змінені, ≤ 70
слів; через повний стек M7 (`MockURLProtocol`) — нове слово дає рівно 1 запит з 4 ключами тіла і `max_tokens`
4096, пакетне доповнення — 1 запит з італійською інструкцією і `max_tokens` 8192. Вручну лишається якість моделі (U19).
